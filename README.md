# Dhaka Regency Hotel & Resort

Light multi-page recreation of [dhakaregency.com](https://dhakaregency.com/).

## Design tokens
- Navy: `#003768` · Deep: `#0a243a` · Teal: `#3caa9f`
- Mist bg: `#e8f0f3` · Body: `#212529`
- Button: navy fill, 6px radius, 16px/700, padding 16×32
- Font: Figtree
- Cards: 12px radius, soft layered shadow

## Routes
| Path | Page |
|------|------|
| `/` | Home (video hero) |
| `/rooms` | Rooms & Suits — **Regular Floor** / **Executive Floor** tabs |
| `/dining` | Dining venues |
| `/meetings` | Meetings & Events |
| `/wellness` | Spa, pool, fitness |
| `/premier-club` | Premier Club |
| `/gallery` | Gallery |
| `/offers` | Offers |
| `/book` | Book / availability form |

## Run
```bash
cd dhakaregency-react
npm install
npm run dev
```
